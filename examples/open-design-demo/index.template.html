颜色相同，字号不同，要求也不同。

普通文字要求至少 4.5:1；大字号文字要求至少 3:1。大字号指至少 24 CSS px，或至少约 18.67 CSS px 的粗体。是否通过按未舍入的计算值判断。

规范里的白字珊瑚色按钮，在普通字号下达不到 4.5:1。本页主要按钮采用同一规范中的深珊瑚色。禁用内容等例外请参见 W3C 说明 ↗。
